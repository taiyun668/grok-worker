# Security policy

## Supported versions

Security fixes are made against the latest released version and the `main` branch.

## Reporting a vulnerability

Use GitHub's private vulnerability reporting for this repository. Do not open a public issue for a suspected credential leak, policy bypass, sandbox escape, unsafe process control, or other security-sensitive defect.

Include the affected version, the smallest reproducible case, the expected safety boundary, and the observed result. Never include real credentials, authentication files, tokens, account identifiers, or local machine paths.

## 安全漏洞报告

请使用本仓库的 GitHub 私密漏洞报告功能。涉及凭据、权限绕过、隔离失效或进程控制的问题，不要公开建 issue，也不要附上真实凭据、账号标识或本机路径。
